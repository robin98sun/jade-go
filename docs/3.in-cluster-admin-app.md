# In-cluster Administrative Application

Since JADE is going to manage resources in the cluster, such as scheduling 3rd-party applications in each node, JADE need the administrative authority to do so

## Enable an account to provisioning apps in-cluster

For example, to enable account `default` in `default` namespace
```
sudo kubectl create clusterrolebinding default-view --clusterrole=cluster-admin --serviceaccount=default:default
```
