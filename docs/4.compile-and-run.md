# Compile and Run

*Supposing you are going to run on Linux*

## Prepare GoLang runtime environment

1. Download GoLang at [official site](https://golang.org/dl/)
    + the binary zip pack is suggested, for example: [go1.15.2.linux-amd64.tar.gz](https://golang.org/dl/go1.15.2.linux-amd64.tar.gz)

1. Prepare directory for GoLang binary, such as `~/lib/go`
    ```bash
    $ mkdir -p ~/lib
    ```
1. Unpack GoLang binary 
    ```bash
    $ tar xzf go1.15.2.linux-amd64.tar.gz
    $ mv go1.15.2.linux-amd64 ~/lib/go
    ```
1. Prepare work space directory for GoLang projects, such as `~/Dev/go`
   ```bash
   $ mkdir -p ~/Dev/go
   ```
1. Export GoLang variables
   ```bash
   $ export GOROOT=~/lib/go
   $ export PATH=$PATH:~/lib/go/bin
   $ export GOPATH=~/Dev/go
   ```
1. Exam the installation
   ```bash
   $ which go         # ~/lib/go/bin/go
   $ go version       # go version go1.15 darwin/amd64
   ```

## Deploy source code of the project

1. Clone the repo or unzip the pack in the work space directory `${GOPATH}`, namely `~/Dev/go`

## compile and run

```bash
$ mkdir ${GOPATH}/aces
$ mv jade-go ${GOPATH}/aces/
$ cd ${GOPATH}/aces/jade-go
$ go install
$ go build -o app
$ chmod u+x app
$ ./app --help
```

## Install dependencies if necessary

1. REST server: `go get github.com/ant0ine/go-json-rest/rest`
1. K8S client: `go get k8s.io/client-go@v0.19.0`
