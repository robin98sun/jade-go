# Local test

1. modify server/agent addresses in env variables
   - `env_variables-master.txt`: the file store runtime environment variables for master node
   - `env_variables-agent-xx.txt`: the file store runtime environment variables for agent nodes

1. modify devops files for quick start
   - `./devops/speed-build.sh`: the file for build and publish JADE image to Docker registry
   - `./devops/speed-deploy.sh`: the file for deploy JADE onto edge cluster

1. backbone of deploying: `./devops/k8s-deployer.py`. you can construct your own scripts for customized deployments with it, it take many arguments
